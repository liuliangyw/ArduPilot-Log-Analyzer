LogScope 使用说明
ArduPilot DataFlash 日志分析 · 全部解析在本地浏览器内完成，不上传任何数据

操作流程

  1. 点击「打开日志」或把 .BIN 文件拖到窗口中
  2. 左侧「字段」中点选数据项 → 曲线叠加显示
  3. 按住左键在曲线上拖动 → 时间光标、地图与读数同步（仅悬停不会改变时刻）
  4. 点击「事件」可跳到模式切换/解锁/报错时刻

快捷键

  • 空格 播放 / 暂停
  • ← → 单步（Shift 加速）
  • Home / End 起点 / 终点
  • 滚轮 缩放；Shift+拖动 / 右键拖动 平移
  • 双击图表复位缩放；拖动分栏边缘可调整面板大小

小技巧

  • 单位不同的数据项会自动放在右侧 Y 轴；也可点标签上的 L / R 手动切换，或切到「归一化」对比量纲差异大的曲线。
  • 在地图上点击轨迹上的任意位置，曲线会跳到对应时刻（地图 → 曲线反向联动）。
  • 底部概览条可拖选新区间；左侧「概览」页显示固件、航程、最大高度等统计，点汇总里的数值会直接跳到对应的最低/最高时刻（放大后也会把该时刻带进视图）。
  • 读数卡左上角是上电时间（相对日志起点），紧挨着的「北京」是由 GPS 时间换算的北京时间（固定 UTC+8；GPS 未定位之前的时段按日志时基回推，整份日志都没有 GPS 时间时不显示）。
  • 速度右侧的「爬升」是当前爬升率（正=上升 / 负=下降），取飞控滤波后的气压爬升率，没有时退回 TECS 估计或 GPS 垂直速度。
  • 调参助手只统计离地之后到触地之前的空中段，起飞前与落地滑跑的姿态偏差、振动都会被剔除（无起落架航模在地面滑跑的振动不计入空中峰值）。面板顶部会写明统计区间。
  • 地图底图按钮循环切换：Esri 卫星、高德卫星、高德混合（卫星 + 路网注记）、高德路网；高德瓦片会自动做 GCJ-02 纠偏，轨迹不会偏移。
