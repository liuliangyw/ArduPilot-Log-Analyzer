这是一个单文件、纯前端的 ArduPilot DataFlash（`.BIN`）日志分析器。界面里有时间曲线、卫星地图和姿态仪，三者靠双向时间联动停在同一个时刻，另外还有事件解释、事故分析和调参助手。日志全部在浏览器本地解析，不会上传到任何服务器。

## 快速开始

1. 双击 `ArduPilot日志分析.html`。Chrome / Edge 直接打开就行，不用安装，不联网也能解析。
2. 点右上角「打开日志」，或者把 `.BIN` 文件拖进窗口。
3. 在左侧「字段」里点数据项，曲线会叠加显示。在曲线上按住左键拖动，时间光标、地图、姿态仪和右侧读数一起走到同一时刻；只悬停不拖动时只显示数值提示，观察位置不变。
4. 点左侧「事件」，右侧会给出这条事件的中文解释（含义、常见原因、排查建议），以及当时飞行的状态。
5. 顶部「事故分析」用来推断坠机主因和其它风险因素；「调参助手」对比目标姿态与实际响应，给出参数修正值。

> 需要底图时请保持联网（卫星影像来自 Esri，街道图来自 CARTO/OSM，都是 WGS-84，与日志坐标一致）。
> 无网络时地图降级为「仅显示轨迹」，其余功能不受影响。

## 一、日志解析（实现要求）

| 要求 | 实现方式 |
| --- | --- |
| 格式识别 | 文件头必须是 `A3 95 80`（新版 DataFlash）。不匹配时给出明确提示，不做盲目解析 |
| 同步与定长 | 每条记录以 `A3 95 + 类型码` 开头；记录总长由 FMT 表给出（含 2 字节同步头与类型码），据此定长跳转，而不是逐字节扫描 |
| FMT 建表 | `80 | 类型码 | 长度 | 名称(4) | 格式串(16) | 列名(64)`，解析出每列的绝对字节偏移、类型、列名，形成「类型码 → 表结构」字典 |
| 列解码 | 按 DataFlash 格式字符表解码：`b/B/h/H/i/I/f/d/q/Q` 原值、`c/C` 百分之一、`e/E` 百分之（高度 cm）、`L` 1e-7（经纬度）、`n/N/Z` 定长字符串 |
| 时间基准 | 统一取首列 `TimeUS`（uint64 微秒，用两个 uint32 拼装，避免 BigInt 的性能损耗），换算成相对日志起点的秒；没有 `TimeUS` 的消息（如 `FILE`）不参与时间轴，免得污染时间范围 |
| 容错 | 任何位置失配只前进 1 字节重新找 `A3 95`，坏块计数后继续；被截断的记录直接丢弃 |
| 分块与进度 | 每 3 MB 让出一次主线程（`setTimeout(0)`），同时刷新「已扫描 xx MB / 已解析 xx 条」，大日志不会假死 |
| 索引 | 每种消息保存 `记录偏移(Uint32Array)` 和 `时间(Float64Array)`，后续「任意字段按需抽取」可以 O(1) 定位（27 MB / 69 万条记录索引约 9 MB） |
| 轨迹抽取 | 同时收集 `GPS`（优先，含航向、速度、星数）和 `POS`（EKF 位置，GPS 不可用时兜底）；剔除经纬度为 0 的无效点，按「距离 > 1.5 km 或时间跳变 > 12 s」切分航段 |
| 事件抽取 | `MODE`（模式切换）、`ARM`（解锁/上锁）、`MSG`（飞控打印）、`ERR`（错误码）按时间排序，作为事件流和曲线上的竖线 |
| 机型识别 | 优先读 `VER.FWS`；没有 `VER` 时用关键参数（`ARSPD_USE`/`TECS_CLMB_MAX` → 固定翼，`PSC_POSXY_P`/`LOIT_ACC_MAX` → 多旋翼…）和消息特征兜底，保证模式名显示正确 |

实测（`00000065.BIN`，27.3 MB）：690,869 条记录、183 种消息、660 s 航程，解析约 1 s。

## 二、数据选择（实现要求）

- **字段树**：按消息类型分组（`ATT` / `GPS` / `VIBE` / `RCOU` …），显示记录条数和最后一帧的数值；`TimeUS` 与元数据消息（`FMT/FMTU/UNIT/MULT/PARM/FILE`）不作为可绘制字段。
- **搜索**：输入即筛（如 `vibe`、`volt`、`Alt`），命中的分组自动展开，500 多个字段里也能很快找到。
- **预设**：姿态、姿态跟踪、高度、电池、振动、GPS、输出、速度、PID 各有一组预设，一键就能把对应曲线加到图上，常用的排障路径不必逐个去点。
- **按需抽取**：只解码被选中的字段，结果按 `消息.字段` 缓存，同一个字段反复选择、来回切换都不额外占内存。每条曲线另外记录采样中位数（判断断线用）、真实极值和 0.2%/99.8% 分位值（显示时抗离群）。
- **单位推断**：按字段名推断并标注（`°`、`m`、`m/s`、`V`、`A`、`%`、`m/s²`、`颗`…），鼠标悬停的读数和坐标轴单位保持一致。

## 三、曲线可视化（实现要求）
<img width="1209" height="975" alt="ScreenShot_2026-11-20_171037_156" src="https://github.com/user-attachments/assets/a1a286a9-5263-4eaf-8448-fe30acadd6d2" />


- **多曲线叠加**：任意条曲线同屏，默认 8 色调色板；标签栏可以单独删除曲线、切换左右轴。
- **双轴 / 归一化**：单位不同的曲线自动落到右轴；量纲差得太多（比如角度对电压）时切到「归一化」，各曲线按自身范围拉伸到 0–100%，鼠标读数仍是真实值和单位。
- **抽稀**：可见区间的样本数超过像素列数时，按像素列做 min/max 抽稀（保留尖峰），66 k 点/条 × 8 条仍能 60 fps 拖动。
- **断线**：采样间隔超过「中位数 × 8」的地方断开，失联、丢包不会画出一条假直线。
- **刻度**：1/2/5 整数步长自动选拍，左轴、右轴、时间轴各自独立计算；时间超过 1 小时后时间轴自动带小时位。
- **事件竖线**：模式切换（蓝虚线 + 顶部标签）、解锁/上锁（绿点线）、错误（红实线），可以一键开关。
- **光标**：竖线贯穿绘图区，各曲线的交点亮起圆点，绘图区内悬浮显示该时刻全部数值和单位。
- **概览条**：底部是全航程的缩略曲线（可见曲线叠加），当前视窗高亮，拖选即可缩放，点击即跳转。

## 四、地图定位（实现要求）

- **自研瓦片地图**：用 Web Mercator 投影和整数级瓦片，缩放按浮点数处理，支持滚轮围绕光标缩放、拖拽平移、双击放大，级别范围 3–18。
- **底图**：卫星影像（Esri World Imagery）和街道图（CARTO/OSM）一键切换；某个源连续失败就自动换下一个，全部失败则进入「仅显示轨迹」的降级模式（灰底网格），并在左下角注明。
- **轨迹**：全程轨迹画白色描边加半透明蓝底，已飞过的部分改成实心深蓝，起点绿圈、终点红点，光标当前落在轨迹的哪一段很容易看出来。
- **飞行器标记**：蓝色圆点加白色描边，箭头指示航向（取自 `GPS.GCrs`，缺失时按相邻点的方位推算），随光标时间移动。
- **跟随 / 全览**：默认跟随，当前点居中，拖动地图后自动退出跟随；一键全览回到整段轨迹的适配视野。比例尺按纬度实时换算。
- **地图 → 曲线联动**：在轨迹附近点击，曲线和读数立即跳到该位置对应的时刻，与曲线到地图的方向合起来构成双向联动。

## 六、中文界面与事件解释

- **参数汉化**：190+ 消息类型和 260+ 高频字段建立了中英对照（`ATT.Roll → 姿态·横滚角`、`VIBE.VibeX → 振动·X 振动`），字段树按「中文名 + 原始键名」双列显示，既好读，也方便和 Mission Planner 对照；不同消息里的同名字段分开处理（`PIDR.P → 比例项 P`、`CTUN.As → 空速`）。
- **中文搜索**：搜索框同时匹配消息名、中文名和原始字段名，`振动`、`电压`、`vibe` 都能命中。
- **事件解释**：点任意事件，右侧卡片给出
  - 分类徽章和时间（模式 / 解锁 / 上锁 / 错误 / 系统消息）；
  - **含义**：模式切换会附上该模式的飞行特性说明（如 FBWA=角度增稳、油门手动）；
  - **可能原因与排查建议**：故障保护、EKF 方差、罗盘异常、推力损失、PreArm 检查等 20+ 条规则；
  - **当时的飞行状态**：模式、相对高度、地速、电压、卫星数、横滚/俯仰；
  - `ERR` 消息按子系统码翻译（1 主循环、12 坠机检测、16 EKF 检查、25 推力损失…）。
- **姿态仪**：右侧常驻一个人工地平仪，方形视窗、8 px 圆角，随光标实时更新横滚、俯仰、航向；视窗里有俯仰刻度、横滚刻度与指针、黄色的目标姿态标记、数字读数和偏差条，超过 ±45° 滚动条变红。
- **读数扩展**：高度下方同时给出 `GPS 海拔` 和 `气压高度`。速度栏右上角是当前里程，累计到光标时刻为止，不到 1 km 用整米，1 km 及以上用三位小数的 km，口径与概览里的「飞行距离」一致，因为取整到米，数值是连续变化的。速度值右边是爬升率（`爬升 ↑7.1` / `↓3.3`，正数上升、负数下降），下方是空速（有 `ARSP` 时标「实测」，否则标「估计」）。电压、电流下方给出已耗电量 mAh 与 Wh，以及剩余百分比。
- **时间与北京时间**：读数卡左上角固定显示 `上电 05:30.0`（相对日志起点），紧挨着的分隔线右侧是 `北京 09:30:21`，与时间同一行，不额外占高度。北京时间固定 UTC+8，不受系统时区影响，以第一次有效的 `GWk + GMS` 为锚点，用日志时基（`TimeUS` 单调递增）向前后推算，所以 GPS 搜星之前的那一段也能给出正确时刻；日期、UTC、GPS 周数在悬停提示里。整份日志都没有 GPS 时间时，这一块自动隐藏。
- **爬升率口径**：依次尝试 `BARO.CRt`（飞控滤波后的气压爬升率，正=上升）→ `TECS.dh`（目标/估计爬升率）→ `GPS.VZ`（NED，向下为正，取负）→ `CTUN.Alt` 差商，固定翼和多旋翼都有值。

## 七、航点事件与飞行汇总

- **航点竖线**：`AUTO`（任务）模式下，每次航点切换在曲线区画一条橙色虚线，顶部标出 `WP3 · 400m · 17m/s`（航点序号 / 目标高度 / 目标速度）。工具栏的地图图钉按钮可以一键开关。
- **地图航点**：同一个开关下，右上角地图在对应位置画出编号航点标记（白底橙边，当前正飞往的航点填充橙色），下方标注 `340m · 17m/s`。标签会互相避让：当前航点优先显示，其余放不下就只留编号，密集区域不会糊成一片。
  - 数据来源：优先用飞控执行期上报的 `CMD` 记录（`CNum` 改变即切换）；固定翼若只在上传时写 `CMD`，则改用 `NTUN` 的 `TLat/TLng`（导航目标点）变化，按坐标就近匹配任务清单得到航点号，再用 `TAW/TAsp` 补充目标高度和速度。
  - 只保留 `AUTO` 模式期间的切换（不同机型的 AUTO 模式号自动识别），`RTL/LOITER` 的目标变化不会误报。
- **飞行汇总**（左侧「概览」）：除固件、时长、距离外，概览里新加了一张整段日志的极值表：相对高度、GPS 海拔、地速、空速、垂直速度、电压、电流、振动峰值、卫星数，每项给出最小值 ~ 最大值和对应的时刻；点数值就能跳到那个时刻，视图已放大时自动平移窗口把时刻带到画面中间（缩放比例不变，全览状态下保持全览）。末尾是累计耗电（mAh / Wh）和累计飞行时间（按 `STAT.Armed` 的解锁区间累加，没有 `STAT` 时用 `Throttle armed/disarmed` 消息）。

## 八、事故分析（炸机归因）
<img width="2560" height="1440" alt="ScreenShot_2026-11-20_170932_100" src="https://github.com/user-attachments/assets/4fcb38f5-2f34-462c-81e3-360c40756260" />


基于日志的统计特征和阈值规则，输出「结论 → 关键数据 → 因素分析 → 时间线」，每条因素都带证据数值、发生时刻（可点击跳转）和处置建议。

| 检测项 | 判据 |
| --- | --- |
| 振动超标 | `VIBE` 峰值 > 30 关注、> 60 严重（ArduPilot 建议 < 30） |
| IMU 削顶 | 统计加速度任一轴 \|a\| > 150 m/s²（约 15G）的样本数 |
| 电压跌落 | 电压跌幅 > 22%（关注）/ > 30%（严重），并统计电流峰值 |
| 动力饱和 | 油门 ≥ 95% 累计 > 2 s（自动兼容 0–1 与 0–100 两种量纲） |
| 姿态失控 | \|横滚\| 或 \|俯仰\| > 60° 持续 > 0.8 s |
| 快速下降 | 1 s 窗口下降率 > 8 m/s（关注）/ > 15 m/s（严重） |
| 姿态跟踪 | 目标 vs 实际 RMS > 12°（关注）/ > 22°（严重） |
| 导航/定位 | 卫星 < 6 颗、HDOP > 2.5、`ERR` 记录、失控保护消息 |
| 坠机特征 | 日志在解锁状态下中断、未上锁即结束、地形冲击 |
| 空速异常（固定翼） | 平均空速与地速差 > 6 m/s（堵塞/未校准/强风） |

结论按因果优先级排序（动力 > 电源 > 错误码 > IMU 削顶 > 振动 > 跟踪 > 中断），并区分「严重（主要矛盾）」和「关注（降低安全余量）」。

## 九、调参助手（目标姿态 vs 实际响应）
<img width="1244" height="1266" alt="ScreenShot_2026-11-20_170944_556" src="https://github.com/user-attachments/assets/d69f36b1-ee84-416f-aaee-42fe102b9d2f" />


- **口径**：直接对比 `ATT.DesRoll/DesPitch`（飞控根据遥控或导航算出的目标姿态）和 `ATT.Roll/Pitch`（实际姿态），另有 `PIDR/PIDP` 的 `Tar/Act` 速率环偏差。
- **阶跃识别**：0.5 s 内目标变化超过 8°、并且新目标保持超过 0.5 s 才计入；记录阶跃次数，区分快阶跃（指令 0.8 s 内完成）和平缓斜坡（LOITER/AUTO 常见），上升时间只统计快阶跃，免得把「指令本身慢」误判成「飞机响应慢」。
- **指标**：跟踪 RMS、平均延迟（目标/实际 50% 交叉时间差）、上升时间 10→90%、超调、稳态误差、振荡次数、达到率。
- **建议规则**：超调 > 25% 或振荡 → 主增益 −12%、D +15%；上升时间 > 1 s 且超调小 → 主增益 +18%；稳态误差 > 2.5° → 积分 +25%；延迟 > 280 ms → 固定翼减小 `RLL2SRV_TCONST`、多旋翼提高角度环 P；振动大 → 降低 `*_FLTD`。
- **参数落地**：从日志的 `PARM` 记录读取当前值，输出「参数名 / 当前值 / 建议值 / 幅度」，并自动适配新旧命名（`RLL_RATE_P` ↔ `RLL2SRV_P`、`PTCH_RATE_*` ↔ `PTCH2SRV_*`、多旋翼 `ATC_*`）；最多给 2 个主改参数，其余列为「后续可选」。
- **一键定位**：每轴提供「查看典型响应」，直接跳到超调最大的那一段，并自动加载目标/实际四条曲线。

> 结论来自统计推断，用来缩小排查范围；参数建议只是起点，不是最终答案，务必逐参数小步验证。

## 性能与内存

- 解析：27 MB / 69 万条，约 1 s；46 MB / 122 万条，约 2 s（受磁盘和内存带宽影响）。
- 索引常驻约 12 字节/条；单条曲线 16 字节/点（时间 + 值），用完可以关闭释放，关掉日志即回收。
- 绘制：只在「脏」时重绘（光标移动 / 视窗变化 / 地图像素变化），瓦片加载完成后局部触发。
- 分析：事故分析和调参助手按需计算，69 万条日志首次约 0.2–0.5 s（阶跃识别要遍历 3.3 万点目标/实际序列），结果不落盘。

## 已知限制

- 仅支持新版二进制 DataFlash（`A3 95 80` 头）；老格式、`.log` 文本日志、`.tlog` 遥测日志都不支持。
- 不解析嵌入文件（`FILE`）、AIS/ADS-B 等长文本消息的内容。
- 底图需要联网；离线时地图只剩轨迹和网格。
- 坐标按 WGS-84 直接投影，不做 GCJ-02 偏移，所以不使用国内偏移坐标系的底图，避免轨迹和影像错位。
- 航点竖线依赖 `CMD` 或 `NTUN`（`TLat/TLng` 列）。极少数机型或固件两者都没有（或全程没进 AUTO），此时按钮只提示「没有航点切换记录」。
- 事故分析和调参建议都是规则加统计推断：阈值按 ArduPilot 的通用经验设定，不针对具体机型、载重；没有坠机日志时只输出风险项。调参结论需要至少一次带明显横滚/俯仰阶跃的增稳模式飞行，纯手动或全程 AUTO 的日志参考价值有限。
