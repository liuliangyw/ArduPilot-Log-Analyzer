# ArduPilot 日志分析器

一个单文件、纯前端的 ArduPilot DataFlash（`.BIN`）日志分析工具，用于查看飞行数据、定位异常、辅助事故排查和调参。

应用本体由 HTML、CSS 和 JavaScript 组成，无需安装或构建。日志全部在浏览器本地解析，不会上传到服务器。

## 主要功能

### 日志解析与曲线分析

- 字段按消息类型分组，支持中英文搜索和姿态、高度、电池、振动、GPS、PID 等常用预设。
- 支持多曲线叠加、双轴、归一化、断线处理和全航程概览。
- 提供时间轴缩放、平移、定位和多倍速播放；事件与航点可显示在曲线上。

### 地图、姿态与时间联动

- 时间曲线、地图、姿态仪和读数卡同步显示同一时刻的数据。
- 拖动时间光标可更新地图与姿态，点击轨迹也可跳转到对应时刻。
- 提供 Esri 卫星影像、高德卫星、高德混合和高德路网四种底图。
- 使用高德底图时，自动将 WGS-84 轨迹、航点和起终点纠偏到 GCJ-02。
- 显示飞行轨迹、起终点、飞行器位置、航向和任务航点，支持跟随与全览。
- 姿态仪显示横滚、俯仰、航向、目标姿态及偏差。

### 中文事件解释

- 消息类型和高频字段提供中文名称，并保留原始键名以便对照 Mission Planner。
- 模式切换、解锁、上锁、错误和系统消息附有含义、可能原因及排查建议。
- 查看事件时，同时显示当时的模式、高度、速度、电压、卫星数和姿态等状态。

### 飞行汇总

- 展示固件、飞行时长、飞行距离、最远离家、累计耗电和累计飞行时间。
- 汇总高度、速度、电压、电流、卫星数等数据的最小值、最大值及对应时刻。
- 空中振动峰值与地面滑跑峰值分开统计。
- 点击汇总数值可跳转到对应时刻。

### 事故分析

-根据日志统计特征和阈值规则，检查振动、IMU 削顶、电压跌落、电流峰值、动力饱和、姿态失控、快速下降、姿态跟踪和导航定位等问题。

-分析结果包括疑似坠机主因、其他风险因素、关键数据、发生时刻和处置建议。固定翼可结合遥控输入、舵机输出、目标姿态和实际响应辅助判断操纵面问题；多旋翼可结合电机输出检查动力异常。

### 调参助手

- 对比目标姿态与实际响应，统计跟踪误差、延迟、上升时间、超调、稳态误差和振荡。
- 仅在有效空中区间统计跟踪与振动数据，排除地面滑跑和撞击时段。
- 检查振动、加速度计削顶及相关飞控参数，并给出分级提示和调整建议。
- 输出参数名、当前值、建议值和调整幅度，可复制为 `.param` 文本后导入 Mission Planner。
- 可跳转到典型响应区间，并自动加载目标姿态与实际姿态曲线。

## 快速开始

1. 使用 Chrome 或 Edge 打开 `ArduPilot日志分析.html`。
2. 点击右上角「打开日志」，或将 `.BIN` 文件拖入窗口。
3. 在左侧「字段」中选择数据项，查看叠加曲线。
4. 拖动曲线上的时间光标，同步查看地图、姿态和读数。
5. 在左侧「事件」中查看中文解释，或使用顶部的「事故分析」和「调参助手」。

## 分析结果说明

事故分析和调参建议基于规则与统计推断，用于缩小排查范围，不能替代对原始日志和实际飞行器状态的核查。未识别到坠机时，仅列出潜在风险。

调参结论需要包含明显横滚或俯仰阶跃的增稳模式飞行数据；纯手动或全程 AUTO 的日志参考价值有限。参数建议仅是调整起点，应逐项小步修改并验证。





## 支持范围与限制

- 仅支持文件头为 `A3 95 80` 的新版二进制 DataFlash 日志。
- 不支持老格式 DataFlash、`.log` 文本日志和 `.tlog` 遥测日志。
- 不解析嵌入文件（`FILE`）以及 AIS / ADS-B 等长文本消息的内容。
- 航点标记依赖 `CMD` 或 `NTUN` 记录；缺少相关记录或未进入 AUTO 模式时，无法显示航点切换。
- 分析阈值采用 ArduPilot 通用经验，不针对具体机型和载重单独标定。
